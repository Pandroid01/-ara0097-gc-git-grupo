Enunciado da Atividade
ARA0097 – Engenharia de Software Atividade Prática – Git &amp; GitHub: Repositório do Grupo + Commit Individual Gerenciamento de Configuração e Controle de Versão (Git e GitHub)
1. Objetivo da Atividade
- Criar e configurar um repositório no GitHub;
- Documentar o projeto e os integrantes no arquivo README.md;
- Garantir colaboração mínima (≥1 commit individual por participante);
- Entregar o link do repositório no SAVA.
2. Contexto e Competências
A gerência de configuração é essencial na Engenharia de Software moderna.
O controle de versão permite rastreabilidade, colaboração e segurança na evolução de sistemas.
O uso do Git e GitHub é prática comum no mercado e possibilita que equipes trabalhem em paralelo,
mantenham histórico de alterações e controlem a integração de código.
3. Entregáveis
- Link do repositório GitHub (público ou privado com convite ao professor);
- Arquivo README.md completo;
- Histórico de commits comprovando a participação de todos os integrantes.
4. Regras e Requisitos
4.1 Um repositório por grupo – nome sugerido: ara0097-gc-git-grupoNN; branch principal main.
4.2 README.md: título, objetivo, integrantes, instruções e comandos úteis.
4.3 Colaboração mínima: cada aluno deve ter pelo menos 1 commit, issue ou PR.
4.4 Visibilidade: público ou privado com convite ao professor.
5. Entrega no SAVA
- Enviar apenas o link do repositório no campo de resposta;
- Um envio por grupo;
- Caso o repositório seja privado, confirmar o convite ao professor antes do prazo.
6. Critérios de Aceite (Checklist)
☑ README.md completo;
☑ ≥1 commit por integrante;
☑ Link funcional;
☑ Acesso garantido ao professor.
7. Avaliação (Rubrica – 10 pts)
Documentação (README.md) – 3 pts
Colaboração (Commits) – 5 pts
Entrega e Acesso – 2 pts
Total – 10 pts
8. Prazo e Política de Atraso
Seguir o prazo informado no SAVA.
Após o prazo, aplica-se a política institucional de atraso da Estácio.
9. Boas Práticas e Ética (IA/Copilot)
- Utilize mensagens curtas e descritivas nos commits;
- Siga padrões de formatação;
- Sempre revise o código gerado por IA antes de incorporar ao repositório.
10. Roteiro Sugerido (Passo a Passo Git)
git init
echo "# Projeto ARA0097" > README.md
git add .
git commit -m "init: README e estrutura básica"
git branch -M main
git remote add origin https://github.com/<usuario>/<repo>.git
git push -u origin main
